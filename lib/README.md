# Simulation 1 Library Files

Load `load_simulation1.R` to source dependencies and functions in order.

- `loading_package.R`: package loading.
- `source.R`: covariance kernels, time transformation, and math helpers.
- `simulation_dgp.R`: `sim()`, the GP-simulated data-generating process.
- `model_inputs.R`: model-input construction.
- `formatting.R`: truth and posterior formatting.
- `fit_multiaddgp.R`: MultiAddGP fitting and hyperparameter scoring.
- `fit_lgpr.R`: LGPR fitting.
- `fit_gam.R`: GAM fitting.
- `metrics.R`: comparisons of estimates to truth.
